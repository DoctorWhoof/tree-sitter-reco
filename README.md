# tree-sitter-reco

Minimal tree-sitter grammar for reco — **highlighter-only**.

## Build dependencies

- `tree-sitter` CLI (`brew install tree-sitter` or `npm install -g
  tree-sitter-cli`)
- That's it.  The grammar.js is pure JavaScript; no node runtime
  needed at build time, just the tree-sitter CLI which handles its
  own JS evaluation.

## Layout

```
tree-sitter-reco/
├── grammar.js              # source of truth — edit this
├── tree-sitter.json        # tree-sitter CLI config
├── package.json            # npm script wrapper
└── src/                    # generated by `tree-sitter generate`
    ├── parser.c            # the parser implementation (committed)
    ├── grammar.json        # internal — don't edit
    ├── node-types.json     # internal — don't edit
    └── tree_sitter/        # internal headers
```

The compiled wasm lives at `../zed-reco/grammars/reco.wasm` (the
output target).
